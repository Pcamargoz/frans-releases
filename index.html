Primeira abertura

O app Frans ainda não tem assinatura paga, por isso o sistema pergunta uma vez antes de abrir. Depois dessa primeira vez, normalmente não pergunta de novo. Escolha o seu sistema:

Windows

Vale para o Frans Orquestrador.

  1. Abra o .exe baixado. Se aparecer “O Windows protegeu seu computador”, clique em Mais informações.
  2. Depois clique em Executar assim mesmo.

Se a tela não aparecer e o Windows só bloquear a abertura

  1. Clique com o botão direito no .exe baixado e escolha Propriedades.
  2. Marque Desbloquear e clique em OK.
  3. Abra o app de novo.

Normalmente o Windows só pergunta na primeira abertura.

Mac

Vale para o Frans Orquestrador.

  1. Abra o .dmg e arraste o app para Aplicativos.
  2. Abra o app uma vez. O Mac vai pedir confirmação.
  3. Vá em Ajustes do Sistema › Privacidade e Segurança e clique em Abrir Mesmo Assim.

Alternativa pelo Terminal

Só se o caminho acima não funcionar. Este comando serve apenas para o app do Frans; não use em outros apps. As aspas são necessárias por causa do espaço no nome.

xattr -dr com.apple.quarantine "/Applications/Frans Orquestrador.app"

Linux

O .deb é a opção principal, no Ubuntu e no Debian.

sudo apt install ./frans-*.deb

O .deb já cuida do sandbox sozinho, sem ajuste extra.

AppImage

1. O AppImage precisa do FUSE 2. O pacote muda conforme a versão.

Ubuntu 24.04 e Debian 13:

sudo apt install libfuse2t64

Ubuntu 22.04:

sudo apt install libfuse2

2. Dê permissão de execução:

chmod +x frans-*.AppImage

3. Abra com dois cliques ou pelo terminal:

./frans-*.AppImage
