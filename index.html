Linux: o app não abre?

No Ubuntu ou Debian, prefira o .deb: sudo apt install ./frans-*.deb. O AppImage é pras outras distribuições:

  1. Dê permissão: chmod +x frans-*.AppImage.
  2. No Ubuntu 22.04 ou mais novo, instale o FUSE 2: sudo apt install libfuse2t64 (no 22.04, libfuse2).
  3. Abra com dois cliques ou pelo terminal.
